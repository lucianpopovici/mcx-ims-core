# 3GPP specifications

The owner places the specification originals here; they are not downloaded by tooling. One set per release, Rel-13 to Rel-20:

- TS 24.229, TS 29.228, TS 29.229, TS 33.203, TS 23.228, TS 23.280
- TS 24.379 (for third-party registration behaviour)
- from I3: TS 29.214, TS 29.514, TS 29.562, TS 29.328, TS 29.329

Release boundaries are extracted from these files (IMS-OP-07). Nothing may cite a clause that has not been checked against them.
